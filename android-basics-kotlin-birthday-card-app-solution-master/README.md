Setup Instructions
Follow the steps below to get the Birthday Card App up and running:

Prerequisites
Before starting, make sure you have the following installed:

Android Studio (latest version)
Java Development Kit (JDK) version 11 or higher
A working Android emulator or a physical Android device for testing

Step 1: Clone the Repository
Open your terminal or command prompt.
Clone the repository with the following command:
git clone https://github.com/your-username/android-birthday-card.git
Replace your-username with your GitHub username.

Step 2: Open the Project in Android Studio
Open Android Studio.
Click on Open an existing project.
Navigate to the folder where you cloned the repository and open the project.

Step 3: Sync the Project with Gradle
After opening the project, Android Studio will prompt you to sync Gradle.
Click Sync Now when prompted, or go to File > Sync Project with Gradle Files to start the sync.

Step 4: Configure the Emulator or Connect a Device
To run the app on an Android Emulator, go to Tools > AVD Manager in Android Studio, and create a new virtual device.
Select a device and system image, then finish the setup.
Alternatively, connect your physical Android device via USB with Developer Mode and USB Debugging enabled.

Step 5: Run the App
Once everything is synced, click the Run button (green play icon) or press Shift + F10.
Choose either your Emulator or Physical Device to run the app.
The Birthday Card App will now build and run on the selected device.
